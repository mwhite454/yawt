========================================================================================================
Component Details
========================================================================================================

Avatar Display:
┌────────┐
│  🖼️    │  - Rounded square (mask-squircle)
│   JD   │  - Shows GitHub avatar if available
└────────┘  - Otherwise shows initials with deterministic color based on username

Role Dropdown (Interactive):
┌──────────────┐
│ Subscriber ▼ │  - Click to open dropdown
└──────────────┘  - Options: Admin, Subscriber, Free
                   - Instantly updates on selection
                   - Shows loading spinner while saving
                   - Admin cannot change own role

Status Badge:
 Active    - Green badge for non-blocked users
 ✅        

 Blocked   - Red badge for blocked users
 🚫        

Action Button (Block):
┌───────┐
│ Block │  - Red button for active users
└───────┘  - Changes to green "Unblock" for blocked users
            - Shows spinner while updating
            - Admin cannot block themselves

========================================================================================================
User Interactions
========================================================================================================

1. Change User Role:
   Admin clicks dropdown → Selects new role → Dropdown shows spinner → Updates → Refreshes table

2. Block User:
   Admin clicks "Block" → Button shows spinner → User marked as blocked → Status changes to "Blocked"
   → Button changes to "Unblock" → Blocked user gets 403 on next request

3. Unblock User:
   Admin clicks "Unblock" → Button shows spinner → Block removed → Status changes to "Active"
   → Button changes to "Block" → User can access app again

========================================================================================================
Security Features
========================================================================================================

✅ Admin-only access - All endpoints require admin role
✅ Self-protection - Admins cannot change own role or block themselves  
✅ Audit logging - All actions logged with timestamp, admin ID, and details
✅ Blocked check - All protected routes check if user is blocked
✅ Privacy - Avatar colors generated deterministically (no user enumeration)
